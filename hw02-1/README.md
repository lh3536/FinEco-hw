# HW02-1：股票收益与组合风险分析

## 数据与样本

- 数据库：CSMAR
- 来源：股票市场系列 → 股票市场交易 → 日个股回报率文件（`TRD_Dalyr`）
- 下载日期：2026-09-28
- 正式样本期：2021-01-01 至 2026-09-16
- 为计算首个交易日收益，额外下载 2020-12 月数据
- 股票数：10 只 A 股，覆盖至少 5 个行业

本次实际使用两份 CSMAR 数据快照：

| 原始 ZIP | 实际日期范围 | 用途 |
|---|---|---|
| `日个股回报率文件231556970(仅供中山大学使用).zip` | 2020-12-01 至 2025-11-28 | 主体样本及样本前交易日 |
| `日个股回报率文件231827931(仅供中山大学使用).zip` | 2025-12-01 至 2026-09-16 | 补齐后段样本 |

核心字段：`Stkcd`、`Trddt`、`Clsprc`、`Dnshrtrd`、`Dnvaltrd`、`Dsmvtll`、`Dretwd`、`Dretnd`。其中 `Dsmvtll` 为历史总市值，组合权重使用上一交易日总市值，不能替换为流通市值或当前市值。

## 环境与运行

```bash
pip install -r requirements.txt
```

打开 `hw02-1.ipynb`，Restart Kernel → Run All。Notebook 使用相对路径读取 `data/raw/`。

## 预期主要输出

- 10 只股票选股表与行业/上市日期核验
- 主键、覆盖期、缺失与异常收益 QA
- 不复权收盘价时序
- 起点为 1 的累计总回报
- 日收益率时序
- 20 个交易日滚动年化波动率
- 描述统计与 Pearson 相关矩阵
- 等权与上一交易日总市值加权组合
- 净值、几何年化收益、年化波动率与最大回撤比较
