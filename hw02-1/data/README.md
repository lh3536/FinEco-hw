# HW02-1 数据获取说明

CSMAR 原始股票数据受学校/数据库授权限制，本目录仅提供复现说明，不公开原始 ZIP/CSV。

## 下载条件

- 数据库：CSMAR
- 路径：股票市场系列 → 股票市场交易 → 日个股回报率文件
- 表：`TRD_Dalyr`
- 频率：日度
- 下载日期：2026-09-28
- 股票代码：600519、600036、601318、600900、601088、601668、600050、601111、000002、002714
- 时间分两段：
  - 2020-12-01 至 2025-11-30（实际最后交易日 2025-11-28）
  - 2025-12-01 至 2026-09-16

## 字段

`Stkcd`, `Trddt`, `Clsprc`, `Dnshrtrd`, `Dnvaltrd`, `Dsmvtll`, `Dretwd`, `Dretnd`

## 本地放置

创建 `data/raw/`，将两份原始 ZIP 原样放入；不要用 Excel/WPS 另存或改写 CSV。Notebook 直接从 ZIP 读取。

原始文件只读；公开仓库不得上传这些 CSMAR 文件。
