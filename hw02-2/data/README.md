# HW02-2 数据获取说明

CSMAR 原始数据受学校/数据库授权限制，本目录仅公开下载条件与字段说明；原始 ZIP/CSV 不上传公开仓库。

## 通用下载条件

- 股票范围：全部 A 股
- 正式分析期：2005—2015
- 财务报表：年度合并报表，截止日期为 12-31
- 资产负债表额外下载 2004-12-31
- 下载日期：2026-09-28

## 原始表

- 上市公司基本信息年度表 `STK_LISTEDCOINFOANL`
- 上市公司上市状态变更表 `STK_ITEMCHANGE`
- 中国上市公司股权性质文件 `EN_EquityNatureAll`
- 资产负债表 `FS_Combas`
- 利润表 `FS_Comins`

资产负债表至少需要：证券代码、证券简称、统计截止日期、报表类型、货币资金、资产总计、短期借款、流动负债合计、长期借款、负债合计、所有者权益合计。

利润表至少需要：证券代码、证券简称、统计截止日期、报表类型、净利润。

## 复现注意

- 原始 ZIP/CSV 只读，不覆盖、不删除。
- 股票代码统一为 6 位字符串。
- merge 键为 `code-year`，每次合并前检查唯一性。
- 行业与产权使用对应年度历史值，不用当前状态覆盖历史。
- 短期/长期借款缺失不能自动填 0。
